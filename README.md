# PROG5121 POE Part 1 - Java Login System

## 📋 Description

This project is part of the PROG5121 Portfolio of Evidence (PoE) - Part 1. It is a simple Java console application that handles:

- User registration
- Login authentication
- Validation for username, password, and South African cellphone number
- Unit testing using JUnit 5

## 🛠️ Features

- ✅ Username validation (must be 5 characters or less, contain a number and special character)
- ✅ Password complexity check (min 8 characters, one uppercase, one number, one special character)
- ✅ Cellphone number validation (must start with '+27')
- ✅ Register and log in user
- ✅ Full JUnit 5 test coverage

## 🧪 Technologies Used

- Java (NetBeans IDE)
- JUnit 5 for testing
- Git for version control

## 🚀 How to Run

1. Open the project in NetBeans.
2. Run the `MAIN` class.
3. Follow the console prompts to register and log in.
